> 一个沉浸式多分支文字冒险 Web 游戏。玩家在迷雾中的维多利亚庄园赴一场神秘晚宴，**四条剧情线 · 四个结局（含好感度触发的隐藏结局）× 旗标变体段落**，12 个计分选择（每维度 3 题多数表决）之后揭晓你的 MBTI 人格画像。内置结局图鉴与 16 型名片夹收集、交互隐喻效果（碎瓷震屏、烛光变色）。

## 玩法

1. 打开 `index.html`（或部署到任意静态托管）。
2. 点击「推开大门」开始，阅读剧情，在节点做出选择。
3. 第六章「主人的提议」分流：**书房（真相线）/ 蓝门（镜厅线）/ 回房（过客线）**——以及一个**隐藏选项**。
4. 隐藏结局「归还」触发条件：晚宴中对主人与沈先生的好感度各 ≥2（克制、打圆场、讲理、接近沈先生……你的处世方式决定门是否为你开）。
5. 全程约 6 分钟、12 个计分选择。结局屏含剧情结局正文 + MBTI 画像 + 专属「庄园角色」描述 + 四维度倾向条。
6. **结局图鉴**（标题屏与结局屏均有展示）记录已解锁结局，重玩可集齐 4/4；**16 型名片夹**记录你测出过的每种 MBTI，集齐 16/16。

## 设计说明（叙事架构借鉴）

对标市面优秀互动叙事作品，吸收了四项核心设计：

- **图结构叙事**（《80 Days》式）：`id/next` 节点图 + 小支点汇合设计，491520 条路径无死局，同样文本量下路径数指数级提升。
- **混合线性结构**（《生命线》式）：总体线性、局部网状。新增 4 个不计分小支点（银相框/旧照片/致辞/僵局）提升选择密度，多数汇合、用旗标记录差异。
- **好感度系统**（《隐形守护者》式）：主人/沈先生双好感度隐性累积，达标才解锁隐藏选项（金色卡片），自然重玩动力。
- **交互隐喻**（《Florence》式 "Play, don't show"）：碎瓷节点震屏骤暗、B 线烛光转蓝、D 线转金——用界面本身传情绪。
- **结局图鉴**：让分支"被看见"（玩家已知 4 个结局待收集），多结局是重玩的核心驱动力。
- **测量完整性**：分支由剧情驱动，MBTI 由选择驱动。任何路径恒经历 12 个计分选择（E/I×3、S/N×3、T/F×3、J/P×3），四条线各自独立覆盖全部 16 型。
- **多数表决与容错**：每维度 3 题（奇数）天然无平局，可容忍单题失误（2:1 仍出确定结果）——对应官方问卷「多观测点平均掉随机波动」的微型版本；四个不计分小支点另携带 0.5 分倾向加权，细化 3:0 / 2:1 的强度区分。
